# Brachiopod Diversity Dynamics

This repository contains the complete R code pipeline used to analyze the macroevolutionary diversity, ecological niche displacement, and paleolatitudinal reorganization of Brachiopoda across the Mesozoic and Cenozoic.

To overcome historical biases, this pipeline integrates global fossil occurrence data from the Paleobiology Database (PBDB) and regional data from the Geobiodiversity Database (GBDB). The GBDB dataset is openly archived on Zenodo ([10.5281/zenodo.21765787](https://doi.org/10.5281/zenodo.21765787)) and will be automatically downloaded by the first script if not already present locally. The pipeline applies stringent coverage‑based rarefaction/extrapolation and a strict ecological filtering protocol to enable symmetrical comparisons between brachiopods and an ecologically equivalent guild of bivalves and echinoderms.

## Pipeline Overview

The analytical pipeline is modular and divided into eight sequential scripts. They must be executed in numerical order, as later scripts depend on the data outputs and workspace archives generated by earlier ones:

1. **`01_Data_Fetching_and_Merging.R`** – Downloads Mesozoic–Cenozoic occurrence data for Brachiopoda, Bivalvia, and Echinodermata from the PBDB via API, and integrates GBDB data (automatically fetched from Zenodo if not already present).  
2. **`02_Data_Cleaning_and_Unification.R`** – Cleans taxonomic nomenclature, resolves synonyms using fuzzy matching, unifies PBDB & GBDB spatial/temporal data, assigns strict international stratigraphic stages, removes cross‑database duplicates, and filters baseline environments.  
3. **`03_Ecological_and_Comparative_Processing.R`** – Harmonises ecological vocabulary between the two databases. Implements genus‑level trait imputation (taxonomic inheritance) to rescue occurrences with missing ecological traits. Exports the cleaned Brachiopoda dataset and extracts an ecologically equivalent guild (epifaunal, stationary suspension feeders) for Bivalvia and Echinodermata.  
4. **`04_Brachiopoda_Diversity_Analysis.R`** – Calculates and visualises coverage‑based standardised diversity (Hill numbers q = 0, interpolated/extrapolated) for Brachiopoda at stage‑level and in 10‑Myr bins. Analyses both the ecologically filtered dataset and the global unfiltered baseline.  
5. **`05_Clade_Specific_Evolution.R`** – Mirrors the logic of Script 04 to separately calculate and plot standardised diversity trajectories for Bivalvia and Echinodermata.  
6. **`06_Consolidate_and_Archive_Diversity.R`** – Consolidates the standardised results across all clades, applies a strict sample‑coverage quality filter (excluding bins where SC < 0.6), and archives the workspace for downstream use.  
7. **`07_Integrated_Macroevolution_Niche.R`** – Generates the final manuscript visualisation pipeline for Brachiopoda. Produces multi‑panel plots for taxonomic scale dependence (species – genus – family), ecological niche shifts (habitat proportions), and paleolatitudinal distributions (density ridge plots).  
8. **`08_Combined_Main_Plots.R`** – Combines Brachiopoda and Bivalvia diversity curves into side‑by‑side comparative panels for the manuscript’s main figures, using identical plot logic and aesthetics (Echinodermata excluded from the main text due to sparse data).

## Prerequisites
- **R** (≥ 4.0 recommended)  
- The following R packages (each script will automatically install any missing packages when run):

  `httr`, `readr`, `dplyr`, `tidyr`, `stringr`, `stringdist`,  
  `iNEXT`, `divDyn`, `ggplot2`, `ggridges`, `patchwork`, `sf`, `cowplot`,  
  `openxlsx`, `purrr`

  - For Figure 6 (paleogeographic maps), the PALEOMAP paleocoastlines (v7, Scotese & Wright) must be downloaded from [Zenodo](https://zenodo.org/record/5469129) and the `CS` folder placed in `./paleocoastlines/CS/` within the working directory. This step is only required if you intend to regenerate the maps.

## Usage
1. **Clone the repository** to your local machine.  
2. **No manual set‑up of the working directory is required.** Each script defines a `custom_dir` variable at the top:  
   - By default it is set to `"D:/PBDB_Project"` (adjust to your preferred location).  
   - If you set `custom_dir <- NULL`, the script will automatically use the folder that contains the `.R` file (works in RStudio).  
3. **GBDB data** are openly archived on Zenodo. Script `01` will download them automatically if they are missing from the working directory; you do **not** need to obtain them separately.  
4. **Run the scripts in numerical order** (`01` through `08`). Intermediate datasets (`.rds` files) and figures will be saved automatically in subdirectories such as `Plot_Data`, `Main_Figures`, and `Supplementary_Figures`.

## Data Availability

- PBDB occurrence data are fetched directly from the Paleobiology Database API.  
- GBDB occurrence data are archived on Zenodo at [https://doi.org/10.5281/zenodo.21765787](https://doi.org/10.5281/zenodo.21765787) and will be downloaded automatically by the pipeline.
